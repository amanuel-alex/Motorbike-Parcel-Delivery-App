# Image Assets Guide

## Hero Image for Login Screen

**Filename:** `delivery_hero.png` or `delivery_hero.jpg`

**Recommended Specs:**
- **Dimensions:** 800x400 pixels (2:1 ratio)
- **Format:** PNG with transparency or JPG
- **Size:** Under 500KB
- **Style:** Motorbike delivery illustration, orange/white theme

### Where to Get Images:

1. **Unsplash** (Free): https://unsplash.com/s/photos/delivery-bike
2. **Freepik** (Free with attribution): https://www.freepik.com/search?query=delivery+motorcycle
3. **Flaticon**: For simple vector icons
4. **Canva**: Create custom illustrations

### How to Add:

1. Save your image to this folder: `assets/images/delivery_hero.png`
2. The code is already configured to use it
3. Run `flutter pub get` 
4. Hot reload the app
